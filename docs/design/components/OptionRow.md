Ligne de réglage dans un groupe sur `surface-raised` cerclé d'une `hairline`, `radius-md`, lignes séparées par une `hairline`. Trois formes : **choix exclusif** (rôle radio, `check` en `accent` sur la ligne choisie, invisible ailleurs), **bascule** (rôle switch, interrupteur `radius-pill` : piste `surface-sunken`, pouce `ink-muted` ; actif : piste `accent`, pouce `on-accent`), **navigation** (chevron `ink-muted`, retourné en RTL). Hauteur minimale `control-md`, texte en `body`, sous-titre en `caption` `ink-muted`, icône Lucide optionnelle au début.

- Les groupes portent un `overline` au-dessus (« LANGUE DE L'INTERFACE », « TRANSCRIPTION »), pas de titre dans le groupe.
- **Au-delà de cinq choix exclusifs, le groupe devient un sous-écran** : une ligne de navigation qui porte le libellé du réglage et, en sous-titre, la valeur courante ; les options vivent sur l'écran suivant, dans un groupe de choix exclusifs. Les Réglages restent ainsi une page que l'on parcourt des yeux, où chaque réglage tient sur une ligne.
- La langue de l'interface et la langue de transcription suivent donc la même forme : « Langue de l'interface · Français » et « Langue de transcription · Français · bonne », chacune ouvrant son écran. Sur l'écran de la langue d'interface, chaque langue s'écrit dans son propre nom, sans icône ni drapeau ; la ligne « Pseudo » n'apparaît qu'en développement.
- Un choix exclusif se fait au premier appui : pas de bouton Valider. Si le choix redémarre l'app (bascule RTL), le sous-titre de la ligne le dit avant.
- Le sous-titre d'une bascule décrit l'état courant en phrase complète (« Désactivée. Vos enregistrements restent sur l'appareil. »), pas « on/off ».
- Le texte visible n'est jamais dupliqué dans l'arbre d'accessibilité : la ligne est le seul nœud focusable, le texte intérieur lui est masqué (D-019) ; `accessibilityLabel` = « Langue de l'interface : Wolof » pour un radio, le libellé pour les autres ; état `checked` ou `selected` porté par la ligne.
- Le consommateur fournit `kind` (`radio` | `switch` | `link`), `label`, `description?`, `icon?`, `checked?`, `onPress`. Le groupe (`OptionGroup`) fournit l'`overline` et le rôle `radiogroup`.
